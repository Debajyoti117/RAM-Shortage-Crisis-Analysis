# • RAM Shortage Crisis Analysis (2024-2028) 

## • Overview
Analysis of 10,000+ RAM listings to uncover 
the global memory shortage crisis and predict 
future prices using Machine Learning.

##  ⁎ Key Insights
- RAM prices rose +503% from 2024 to 2027
- 100% listings became shortage-inflated by 2027
- Inventory dropped from 13 weeks to 5 weeks
- AI & GPU demand is the #1 price driver
- Predicted 2027: $70/GB | 2028: $68/GB

##  ⁎ Tools Used
- Python (Pandas, Scikit-learn, Matplotlib)
- PostgreSQL (Database)
- Power BI (Dashboard)
- Gradient Boosting ML Model
